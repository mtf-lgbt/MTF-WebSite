## はじめに

MTF.LGBT 利用マニュアルへようこそ。MTF.LGBT はトランスジェンダー群体に向けた公益プロジェクトで、ドメイン、メール、コンテンツ公開と交流など、できる範囲のサービスを提供したいと考えています。本マニュアルは、現在よく使われる機能の申請方法と利用方法をまとめたもので、サードレベルドメイン申請、メール登録、記事と Subtitle の投稿、RSS / メール購読、翻訳への貢献、相互リンク、Bug 報告、Pull Request の提出、協力についてなどを含みます。

初めてここに来た方は、まず目次から必要な部分を探してください。一部のサービスを利用したことがある場合でも、いつでも参照できる説明書として本マニュアルを活用してください。プロジェクトは管理人とボランティアによって維持されており、ドメイン更新料、メールなどの基盤は寄付と限られたリソースに依存しています。そのため、必要な分だけ申請し、適切に利用してください。ドメイン申請や記事投稿などは通常審査が必要です。気長に待ち、重複提出を避けてください。

マニュアルの内容はサイト機能の更新に合わせて調整されます。マニュアルとページの実際の状況が一致しない場合は、サイトの実際のページおよび Issue 内の返信を優先してください。改修中または未完成の機能についても、該当する章で注記します。問題が発生した場合は、まず関連する章を読むことをおすすめします。それでも解決しない場合は GitHub Issue で質問し、できるだけスクリーンショット、リンク、再現手順を添えてください。

利用、投稿、翻訳、フィードバック、寄付をしてくださるすべての方に感謝します。このマニュアルが MTF.LGBT をよりスムーズに利用する助けとなり、より多くの人が一緒に維持管理に参加してくれることを願っています。ここがトランスジェンダーの人々にとって本当に役立つ空間になることを願っています。

### 翻訳
> この部分は比較的重要なので、README.md にも明記します。

まず、私たちのプロジェクトに翻訳を提供してくださり、ありがとうございます。私たちの翻訳システムは、キー翻訳とコンテンツ翻訳の2つの部分に分かれています。

キー翻訳とコンテンツ翻訳の違い：

| 項目 | キー翻訳 | コンテンツ翻訳 |
| --- | --- | --- |
| 説明 | タイトル、ボタン文字、リンクテキストなどは、ネイティブの i18n 国際化モジュールを使って翻訳します。基本的に変更されません | 長文、イベント、通知など、JSON ファイルに入れるのが不便なテキストにはコンテンツ翻訳を採用します。たとえば「私たちについて」ページです。変更頻度はキー翻訳よりやや多くなります |
| 特徴 | 翻訳内容は厳密に一対一対応です。ただし、1つのファイルに内容が多すぎる場合は、一部のキーを分割して別ファイルに置いても構いません。（管理人からの警告：分割しすぎて他の人に分からないほど抽象的にしないでください） | 言語ごとに全く異なる文章を書くことができ、地域限定のイベント通知を追加することもできます。単純な翻訳というより、むしろロケール設定に近いものです。ただし、この「ロケール設定」は翻訳設定の変化に応じて変わるものであり、普段見かけるように言語が1つの設定項目、地域が1つの設定項目というわけではありません |
| 場所 | ```./src/i18n``` | ```./src/routes``` |

#### キー翻訳

まず、現在（2026-10-24）のディレクトリ構造を確認しましょう：
```dash
src/i18n
├── i18n.js
├── ja
│   ├── blogs.js
│   ├── friends.js
│   ├── home.js
│   └── master.js
└── zh-cn
    ├── blogs.js
    ├── friends.js
    ├── home.js
    └── master.js
```
この中で、```i18n.js``` は登録ハブのような役割を果たし、基本的な翻訳作業はここに集約されます。

##### 登録

まず、先頭でルートファイルを import する必要があります。これをあなたの言語翻訳の起点とします。通常、ルートファイルは ```src/i18n/<Language Code>/master.js``` に作成します。  
次に、先ほど import した名前を message に追加します。たとえば ```import enus from './en-us/master.js'``` と書いた場合、message には ```enus``` と書きます。

##### 構成

特に説明することはありません。他の言語の構成をコピーすればOKです。重点が1つだけあるので注意してください：

これがルートファイルの基本構成です
```js
const zhcn = {
    { ··· }
}
export default zhcn;
```
「const」の後ろの単語と「default」の後ろの単語が一致し、さらに ```i18n.js``` 内の対応する import 名とも一致していることだけを守ればOKです。

#### コンテンツ翻訳

この部分は比較的簡単です。```/src/routes/``` 内にフォルダを作成し（まだ誰も翻訳していない場合）、そのフォルダ内に翻訳したいページ名に ```.md``` を付けたファイルを作成します。たとえば「私たちについて」ページなら ```about.md``` を作成します。ただし例外があり、ホームページ、つまり一般的なプログラム文脈での「index」の場合は、```index.md``` ではなく ```home.md``` を作成する必要があります。

また、フォルダを作成するときのフォルダ名は、```src/i18n/i18n.js``` で言語ルートファイルを import するときの名前にしてください。

書き方については、そのまま [vitepress の wiki](https://vitepress.dev/guide/getting-started) を参照してください。関連プラグインはこれを vitepress として処理するためです。このプロジェクトが正真正銘の Vue プロジェクトであっても変わりません。

#### 設定ボタンと setting.js

```src/components/setting.vue``` の98行目のリストに追加するだけでOKです
